## Search tells you when nothing on file covers what you asked

- **"No covering document on file."** Search for a lot, a production date or a
  supplier and the page now checks each document's own fields. When nothing on
  file actually covers what you asked for, it says so first, before anything
  else.
- **Near misses are listed separately, with the reason.** Documents that look
  close — the same supplier, a similar lot, a nearby date — appear under
  *Nearby — does not match*, and each one says what it is missing. A near miss
  is never shown as an answer.
- **Files still waiting for review are marked as not reviewed.** A matching file
  that is still in the Review Queue appears under *In the Review Queue — not on
  file yet*, with a link to open it there.
- **AI search shows what it could not apply.** If part of your question could not
  be turned into a filter, it is listed above the results instead of the search
  quietly loosening.
- **Plurals and gallons match.** "5 gallon bags" finds "5 Gallon Bag", and "gal"
  and "gallon" find each other.
- The Search help panel now describes all five tabs (All, Documents, Orders,
  Customers, Bundles) and the three result groups.

## Review Queue: one action for a supplier's file

- **Approve and decide in one step.** A file a supplier sent against a request
  shows the requirements the supplier says it covers. You approve it and, in the
  same action, accept those requirements, send it back with a note the supplier
  reads, or decide later. Nothing is accepted just because the supplier ticked it.
- **"Sales sheet, not a spec sheet."** A new rejection reason for when a supplier
  sends a sales sheet in place of the spec sheet you asked for.

## Lot matches are always suggestions

- **A person confirms every lot match.** Matching a certificate to an order's lot
  no longer links them on its own. Suggested matches appear on the order page and
  the lot page with their confidence and the reason, each with one-click Confirm
  or Reject. On the COA Fulfillment report a line with only a suggestion still
  counts as missing its COA, and shows *Match suggested* with a link to the order.
