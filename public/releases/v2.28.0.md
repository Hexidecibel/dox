## You already have this

A file that is already on file used to disappear quietly before anyone saw it.
Now it is raised for a person to decide.

### Added

- [existing] **A file you already have is raised, not hidden.** It arrives in the Review Queue as "You already have this", naming the document it matches and why: the same file byte for byte, or a newer revision with the same document number, certificate number or COA lot set. The Import page shows the same notice right after upload.
- [existing] **Three choices:** *Replace existing* (the default) makes the file the next version of the same document, and earlier versions stay in version history. *Keep as a new document* files it separately. *Discard* closes it as "Discarded: already have it" without touching the document on file.
- [existing] Nothing is decided by omission: a matched file cannot be approved until one of the three is chosen. A Replace with no renewal answer keeps the renewal date already on the document.
