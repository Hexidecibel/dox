## Review what suppliers send back

v2.8.0 gave suppliers a no-login link to answer a document request, and read
what they uploaded on arrival. What it did not give our own staff was a place
to look at that file and decide whether it actually satisfies what was asked.
This release is that place.

- [existing] **Arrivals inbox.** A new *Arrivals* screen under Requests lists every file a
  supplier sent back through a request link that nobody has decided yet, with
  what the supplier said each file covers.
- [existing] **"What came back" on each request.** A request now shows the files that
  arrived against it, line by line, and which document a line was accepted on.
- [existing] **Decide dialog.** For each thing a file was claimed to cover, a reviewer can
  **accept** it — once the file has been approved in the Review Queue — which
  marks the request line accepted and confirms the requirement link; or **send it
  back** with a reason, which the supplier sees on their link. A reviewer can
  also record that a file covers something the supplier did not tick.
- [existing] **Review Queue context.** A queue item that came from a request link shows
  what the supplier said the file covers, and the Arrivals inbox opens straight
  to that item.
- [existing] **File stays viewable after approval.** An arrival's file can still be opened
  from the request once it has become a document.

Still true: a supplier's upload never moves a request's progress on its own.
Approving an extraction and accepting a request line remain two separate
decisions, made by a person (migration 0104).
