## Rebuild search from the admin screen

### Added

- [existing] **A "Rebuild search index" button on Admin › Processing Status** (super admins). It rebuilds free-text search for every organization in one click and says how many documents it re-indexed. You need it after an update that changes what search reads; everyday edits keep search current on their own.
