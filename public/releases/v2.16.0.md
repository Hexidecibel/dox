## Each supplier's lot format, declared

- [config] **A supplier's lot format can now be declared on the supplier** (Supplier ›
  **Lot format**). Pick or describe the format, try any lot code in the
  **tester**, and preview how every lot already on file reads against it.
  Formats are kept as versions, so an earlier decode stays explainable after a
  change.
- [config] **The review queue flags a lot that does not fit its supplier's format**, or
  whose date code disagrees with the date printed on the certificate. It only
  flags — nothing is changed for you.
- [config] **When a certificate states no production date, search shows the date the lot
  code implies** as "likely — confirm". It is never counted as a match.
- [existing] **Extraction no longer converts Julian date codes itself.** Dates are copied
  exactly as printed; only a declared lot format decodes a lot code.

### Fixed
- [existing] **API keys: an expiry date now means the key works through the end of that
  day.** The form shows exactly when a key will stop working and refuses dates
  in the past.
