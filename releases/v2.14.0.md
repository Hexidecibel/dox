## The portal recognises a file it has already seen

- [existing] **An exact copy of a document you already approved no longer creates a new
  review item.** It is recorded as *received again* on that document, with
  **Review anyway** if you need to look at it.
- [existing] **An exact copy of a file already waiting is folded into that card**, which
  shows how many times it arrived (*Received 2×*).
- [existing] **A copy of a file that was rejected comes back with a note** saying when it
  was rejected and why.
- [existing] **Suppliers see their upload received exactly as before.**
- [existing] **Only byte-identical files are recognised.** A re-scan of the same paper
  still comes through as new.
