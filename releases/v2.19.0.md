## The test names your limits never saw

- **Spec Limits now shows the analyte names printed on certificates that no
  configured test recognises** — with how many results each one covers and an
  example document to look at. A limit whose analyte is spelled differently
  from what the supplier prints never runs, and nothing used to say so.
- **One click per fix:** add the printed spelling as an alias on an existing
  test, create a new test from it, or mark it **not a test** (for the `Flavor`,
  `Color` and `LOT CODE` rows every results table carries). Dismissals are
  undoable and stay readable, with who dismissed them and when.
- **A limit's version number now changes only when its threshold does.**
  Editing a note or moving a limit between tiers no longer looks like a new
  revision, and the version in force is recorded with every stored result.
- **The spreadsheet importer can set how much a limit matters**, so a workbook
  of limits arrives already ranked instead of all at the middle tier.
- **The review queue says when a buffer or control row was recognised** and
  deliberately not judged as product.
