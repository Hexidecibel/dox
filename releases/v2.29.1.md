## The prompts name no one

The instructions the portal gives the model when it reads a document no longer
contain any organisation's or supplier's name.

### Changed

- [existing] **Your own organisation is never read as the supplier.** The rule that keeps the "Ship To" party from being filed as the supplier used to name one organisation. It now states the general rule and uses your organisation's name as recorded in the portal.
- [existing] The worked examples the model is shown use made-up suppliers, customers and order numbers of the same shape as before.
- [existing] Measured before release on two sets of real and test documents: 288 of 300 graded values correct both before and after, and one fewer invented value.
